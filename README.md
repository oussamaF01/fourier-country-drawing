# 🌍 Fourier Country Drawing

Reconstruct country outlines using the **Discrete Fourier Transform (DFT)** and visualize the process with rotating epicycles.

### ✨ Features
- Extract country boundaries from GeoJSON data.
- Represent outlines as complex-valued signals.
- Reconstruct shapes using Fourier coefficients.
- Animate rotating circles with Python.

### 🛠️ Technologies
Python · NumPy · Matplotlib · Shapely

### 🚀 Installation

```bash
pip install numpy matplotlib shapely
python Shape_maker.py
```
